# Practice Log

บันทึก practice session ของคุณ — ใช้ `practice-log-template.md` เป็น entry format

เป้าหมาย: เห็น pattern ว่า concept ไหนที่คุณยังงง หรือ revisit บ่อย

## ตัวอย่างการใช้

```
log/
├── README.md                 # ไฟล์นี้
├── practice-log-template.md  # template สำหรับแต่ละ session
└── 2025-03.md                # log รายเดือน (สร้างเอง)
```

คุณจะ organize ยังไงก็ได้ — รายวัน รายสัปดาห์ หรือต่อ kata ก็ได้
