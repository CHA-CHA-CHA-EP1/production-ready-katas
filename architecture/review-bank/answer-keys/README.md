- **Flaw** — อธิบาย flaw ที่ plant ไว้
- **Why it fails in production** — scenario จริงที่ทำให้พัง
- **Fix** — วิธีแก้ที่ถูกต้อง
- **Severity** — Critical / High / Medium / Low
