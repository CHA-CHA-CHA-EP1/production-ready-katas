# Submissions

บันทึก practice submission ของคุณไว้ที่นี่

## Structure

```
submissions/
└── YYYY-MM-DD-<kata-name>/
    ├── diagram.png          # หรือ .svg / .drawio / .excalidraw
    ├── decisions.md         # กรอกจาก templates/key-decisions-template.md
    └── notes.md             # (optional) ข้อสังเกต, คำถามที่ค้างอยู่, สิ่งที่เรียนรู้
```

## Privacy

`submissions/` อยู่ใน `.gitignore` โดย default — งาน practice ของคุณเป็น private
ถ้าต้องการ track ใน git ให้ลบ entry ออกจาก `.gitignore` ด้วยตัวเอง

## Example

```
submissions/
└── 2025-03-01-cidr-planning/
    ├── diagram.png
    ├── decisions.md
    └── notes.md
```
