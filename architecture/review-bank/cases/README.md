# Review Bank — Cases

แต่ละ case = design submission จาก "app team" ที่มี flaw ซ่อนอยู่ 5-8 จุด

## วิธีใช้

**วิธีที่ 1 — ทำเอง:**
1. อ่าน case (diagram + narrative)
2. เขียน design review ของคุณ — ระบุ flaw ที่เจอ พร้อม severity และวิธีแก้
3. เปรียบเทียบกับ answer key ใน `../answer-keys/`

**วิธีที่ 2 — ใช้ AI (แนะนำ):**
```
"Read skills/reviewer-mode.md first, then start a review session"
```
AI จะเล่นเป็น app team ส่ง design มาให้คุณ review — และจะ grade review ของคุณ
โดยยังไม่เปิด answer key จนกว่าคุณจะ review เสร็จ
